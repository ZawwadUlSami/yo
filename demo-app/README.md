# Reddit Growth Tool - Demo Version

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/YOUR_USERNAME/YOUR_REPO)

This is a **demonstration version** of the Reddit Growth Tool - an AI-powered platform for growing your Reddit presence.

## 🎭 Demo Mode Features

This demo uses **mock data** and doesn't require any API keys or setup. You can:

✅ Explore the full UI and user experience
✅ Generate AI posts (using templates, not real AI)
✅ Analyze subreddits (with simulated data)
✅ Schedule and manage posts
✅ View analytics dashboards
✅ Test all features without Reddit API

❌ **Not included in demo:**
- Real Reddit posting
- Actual AI generation (uses templates)
- Live subreddit data
- Real analytics from Reddit

## 🚀 One-Click Deployment

### Deploy to Vercel (Easiest - 2 minutes)

1. **Fork this repository** to your GitHub account
2. **Go to [Vercel](https://vercel.com)**
3. Click **"New Project"**
4. **Import your forked repository**
5. Click **"Deploy"**
6. Done! Your app will be live in ~30 seconds

No configuration needed - it just works!

### Or Deploy Manually

#### Option 1: Vercel CLI
```bash
npm install -g vercel
cd demo-app
vercel
```

#### Option 2: Netlify
```bash
npm install -g netlify-cli
cd demo-app
npm install
npm run build
netlify deploy --prod --dir=build
```

## 💻 Run Locally

1. Clone the repository:
```bash
git clone <your-repo-url>
cd demo-app
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000)

## 📋 How to Use

### 1. Login/Register
- Use **any email and password** (it's all local, no real authentication)
- For demo: email `demo@example.com`, password `demo123`

### 2. Explore Features

**Dashboard**
- View stats and recent posts
- Quick access to all features

**AI Post Generator**
- Enter any topic and subreddit
- Choose writing style
- Generate posts instantly (using templates)

**Subreddit Analyzer**
- Analyze any subreddit
- See trending topics and best posting times
- View subreddit rules

**Post Scheduler**
- Manage your posts
- Schedule for later
- "Publish" to simulate posting (shows success message)

**Analytics**
- View performance metrics
- See top posts
- Track subreddit stats

### 3. Test the Features

The app uses **localStorage** to save your data, so:
- Your generated posts persist between sessions
- Data is stored only on your browser
- Clear browser data to reset
